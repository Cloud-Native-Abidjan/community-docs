# La communauté

## Cloud Native Abidjan

Cloud Native Abidjan est une communauté CNCF en Côte d'Ivoire dédiée au partage, à l'apprentissage et à la contribution autour de l'écosystème Cloud Native.

### Sujets

- Kubernetes
- Docker & conteneurs
- DevOps / DevSecOps
- Platform Engineering
- GitOps
- Cloud & Infrastructure
- Observability / SRE
- CI/CD
- Cloud Security
- AI / Cloud Native AI
- Open Source

### Notre esprit

**Learn • Share • Build • Together**

La communauté est ouverte aux débutants comme aux professionnels expérimentés.
