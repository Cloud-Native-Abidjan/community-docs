# Cloud Native Abidjan

**Learn • Share • Build • Together**

Bienvenue sur l'espace de référence de **Cloud Native Abidjan**, communauté CNCF en Côte d'Ivoire.

Nous réunissons les personnes intéressées par le **Cloud Native, Kubernetes, Docker, DevOps, DevSecOps, Platform Engineering, GitOps, Cloud, Observability, AI et Open Source**.

## 🚀 Par où commencer ?

Si vous souhaitez rejoindre Cloud Native Abidjan, le parcours est simple :

1. Ouvrir la page officielle CNA sur Open Community Groups.
2. Cliquer sur **Join group**.
3. Se connecter avec son compte Linux Foundation ou en créer un.
4. Revenir sur la page CNA et rejoindre le groupe.
