# Rejoindre Cloud Native Abidjan

Bienvenue dans la communauté 👋

L'inscription est gratuite et ne prend que quelques minutes.

<a class="md-button md-button--primary" href="https://ocgroups.dev/cncf/group/cloud-native-abidjan">Rejoindre maintenant</a>

<div class="cna-steps">
<div class="cna-step"><strong>1 · Ouvrir</strong><span>La page CNA</span></div>
<div class="cna-step"><strong>2 · Se connecter</strong><span>Linux Foundation</span></div>
<div class="cna-step"><strong>3 · Créer</strong><span>Un compte si nécessaire</span></div>
<div class="cna-step"><strong>4 · Rejoindre</strong><span>Le groupe CNA</span></div>
</div>

<div class="cna-note"><strong>Vous avez déjà un compte Linux Foundation ?</strong><br>Passez directement à l'étape 2.</div>

## 1. Ouvrir la page Cloud Native Abidjan

Ouvrez la <a href="https://ocgroups.dev/cncf/group/cloud-native-abidjan">page officielle de Cloud Native Abidjan</a>, puis cliquez sur **Join group**.

<div class="cna-screenshot">
<a href="../assets/images/01-join-community.png"><img src="../assets/images/01-join-community.png" alt="Page Cloud Native Abidjan avec le bouton Join group" loading="lazy"></a>
<div class="cna-caption">1 · Ouvrir la page CNA et cliquer sur <strong>Join group</strong></div>
</div>

## 2. Se connecter

Si vous n'êtes pas encore connecté, un message vous indique que vous devez vous connecter.

Cliquez sur **OK**, puis sélectionnez **Linux Foundation SSO**.

<div class="cna-screenshot">
<a href="../assets/images/02-login-required.png"><img src="../assets/images/02-login-required.png" alt="Message demandant de se connecter" loading="lazy"></a>
<div class="cna-caption">2 · Confirmer la connexion</div>
</div>

Puis choisissez **Linux Foundation SSO**.

<div class="cna-screenshot">
<a href="../assets/images/03-linux-foundation-sso.png"><img src="../assets/images/03-linux-foundation-sso.png" alt="Écran de connexion Linux Foundation SSO" loading="lazy"></a>
<div class="cna-caption">3 · Choisir Linux Foundation SSO</div>
</div>

Si vous avez déjà un compte, connectez-vous avec vos identifiants.

## 3. Créer un compte si nécessaire

Vous n'avez pas encore de compte Linux Foundation ? Cliquez sur **Create an account**.

<div class="cna-screenshot">
<a href="../assets/images/04-create-lfid-account.png"><img src="../assets/images/04-create-lfid-account.png" alt="Formulaire de création d'un compte Linux Foundation" loading="lazy"></a>
<div class="cna-caption">4 · Cliquer sur <strong>Create an account</strong></div>
</div>

Renseignez simplement :

- Prénom
- Nom
- Email
- Nom d'utilisateur
- Mot de passe

Puis cliquez sur **Create Account**.

<div class="cna-screenshot">
<a href="../assets/images/05-create-account-submit.png"><img src="../assets/images/05-create-account-submit.png" alt="Bouton Create Account sur le formulaire Linux Foundation" loading="lazy"></a>
<div class="cna-caption">5 · Renseigner les informations puis créer le compte</div>
</div>

## 4. Revenir sur CNA et rejoindre le groupe

Une fois votre compte créé et connecté, retournez sur la <a href="https://ocgroups.dev/cncf/group/cloud-native-abidjan">page Cloud Native Abidjan</a>.

Cliquez à nouveau sur **Join group**.

<div class="cna-note"><strong>C'est fait 🎉</strong><br>Vous faites maintenant partie de <strong>Cloud Native Abidjan</strong>.</div>

## Pourquoi rejoindre CNA ?

- 📚 Découvrir et apprendre
- 🎤 Participer aux meetups et proposer des sujets
- 🛠️ Participer à des ateliers pratiques
- 🤝 Échanger avec d'autres passionnés du Cloud Native
- 💡 Partager votre expérience
- 🌍 Contribuer à l'écosystème Cloud Native en Côte d'Ivoire
